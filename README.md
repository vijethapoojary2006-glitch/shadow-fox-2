shadow fox task 2
Task 1 – Bank Account Management System

This project is developed using Java to manage basic banking operations.
The system allows users to create a bank account, deposit money, withdraw money, check account balance, and view transaction history.
JUnit testing is used to test deposit and withdrawal functions to ensure the program works correctly.



Task 2 – Inventory Management System

This project is developed using Java Swing GUI for managing inventory items.
The system allows users to add, update, delete, and clear inventory records through a graphical user interface.
It provides an easy way to manage item names and quantities using buttons and text fields.
